# AWS DevOps Lab

Hands-on AWS learning repository focused on DevOps, cloud infrastructure,
networking, security, troubleshooting, and automation.

## Topics

- IAM
- VPC Networking
- EC2
- EBS / S3
- Load Balancing
- CloudWatch
- ECR / EKS
- RDS
- Terraform

## Region

Primary lab region: `eu-central-1` (Frankfurt)

## Principles

- Prefer CLI + reproducible configuration over console-only work
- Understand every resource before automating it
- Create controlled failures and troubleshoot them
- Delete temporary resources after labs
- Never commit AWS credentials or secrets
